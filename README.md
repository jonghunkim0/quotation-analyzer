# 원가구성 비교 분석 도구 (웹 버전)

제조 장비 견적서의 원가구성을 비교·분석하는 **완전 오프라인 웹 도구**입니다.
Python 설치나 서버 없이, **`index.html`을 더블클릭**하는 것만으로 사용할 수 있습니다.

---

## 🚀 실행 방법 (설치 불필요)

1. 이 폴더를 원하는 곳에 복사합니다.
2. **`index.html` 파일을 더블클릭**합니다.
3. 브라우저(Chrome / Edge 권장)에서 자동으로 열립니다.

> ✅ 인터넷 연결이 **전혀 필요 없습니다.** 모든 라이브러리가 이 폴더 안에 들어 있습니다.
> ✅ 모든 데이터는 **당신의 브라우저 안에서만** 처리됩니다. 외부로 전송되지 않습니다.

---

## 📁 폴더 구성

```
webapp/
├── index.html          ← 이 파일을 더블클릭하면 됩니다
├── app.js              ← 분석 로직 (분류·집계·파싱)
├── README.md           ← 이 사용설명서
└── lib/                ← 번들링된 라이브러리 (수정하지 마세요)
    ├── xlsx.full.min.js    (Excel 파싱 - SheetJS)
    ├── echarts.min.js      (차트 - ECharts)
    ├── pdf.min.js          (PDF 파싱 - pdf.js)
    └── pdf.worker.min.js   (PDF 워커)
```

> ⚠️ `index.html`, `app.js`, `lib/` 폴더는 **함께** 있어야 합니다.
> `lib` 폴더만 따로 옮기면 동작하지 않습니다.

---

## 📊 사용 절차

1. **파일 업로드** — 견적 Excel(`.xlsx`/`.xls`) 또는 PDF(`.pdf`)를 끌어다 놓거나 클릭해 선택합니다.
   - **1개 파일**을 올리면 그 파일의 원가구성만, **2개 이상**을 올리면 업로드 순서대로 비교 차트가 만들어집니다.
   - 비교안 이름은 **파일명(확장자 제외)** 으로 자동 지정됩니다 (예: `견적가.xlsx` → "견적가").
2. **▶ 분석 시작** — 파일 업로드가 끝나면 **"분석 시작"** 버튼을 누릅니다.
   - 이 버튼을 누르기 전까지는 항목표·집계표·차트가 비어 있습니다.
   - 버튼을 누르면 항목 검토표, 비용 집계표, 원가구성 차트가 한꺼번에 표시됩니다.
   - 파일을 추가/삭제하면 분석이 초기화되어 다시 "분석 시작"을 눌러야 합니다.
3. **분류 검토** — 자동 분류 결과를 확인하고, 틀린 항목은 "최종분류" 셀에서 바로 수정합니다.
   - 수정하면 품명 키워드가 **자동으로 규칙으로 학습**되어 다음부터는 자동으로 맞습니다.
4. **차트 확인** — 원가구성 비교 대시보드를 확인합니다.
   - ① 1차: 비용 그룹 비교 (재료비/인건비/기업이윤/기타)
   - ② 2차: 재료비 세부 항목 / ③ 2차: 인건비 세부 항목
   - 표시 단위(원/천원/백만원/억원), 사급품 처리, 강조 비교안 등을 사이드바에서 조절합니다.
5. **내보내기** — 견적항목 / 집계표 / 증감분석 / 분류규칙을 **Excel(.xlsx)** 파일로 저장합니다.
   - 차트는 "📷 차트 PNG 저장" 버튼으로 이미지로 저장할 수 있습니다.

---

## 🔒 보안

- 모든 파싱·분류·집계·차트가 **브라우저 로컬**에서 수행됩니다.
- 견적 데이터는 **어디로도 전송되지 않습니다.** (오프라인에서도 동작)
- 학습된 분류 규칙은 브라우저의 `localStorage`에 저장됩니다 (이 PC·이 브라우저에만).

## ❓ 자주 묻는 질문

**Q. 인터넷이 안 되는 환경에서도 되나요?**
A. 네. 모든 라이브러리가 폴더 안에 번들링되어 있어 완전 오프라인에서 동작합니다.

**Q. 다른 사람에게 어떻게 전달하나요?**
A. 이 `webapp` 폴더 전체를 지퍼로 압축해 보내면 됩니다. 받은 사람이 지퍼를 풀고 `index.html`을 더블클릭하면 됩니다.

**Q. 분류가 잘 안 될 때는?**
A. "최종분류" 셀에서 직접 고르면 됩니다. 한 번 고르면 그 품명 키워드가 규칙으로 저장되어 다음부터는 자동으로 맞습니다. "7. 분류 규칙 관리"에서 규칙을 직접 추가/삭제할 수도 있습니다.

**Q. 데이터가 외부로 나가나요?**
A. 절대 아닙니다. 모든 처리가 브라우저 안에서 끝나며, 네트워크 요청이 없습니다.
